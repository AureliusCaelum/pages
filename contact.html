Kontakt

Haben Sie Fragen oder Anregungen? Wir freuen uns auf Ihre Nachricht!

Kontaktmöglichkeiten

Da dies eine statische Website ist, die auf GitHub Pages gehostet wird, können wir kein direktes Kontaktformular anbieten. Sie können jedoch auf folgende Weise mit uns in Kontakt treten:

GitHub

Besuchen Sie unser Repository auf GitHub und erstellen Sie ein Issue oder Pull Request:

github.com/AureliusCaelum/pages

E-Mail

Für allgemeine Anfragen können Sie uns auch per E-Mail erreichen. Die E-Mail-Adresse finden Sie in unserem GitHub-Profil.

Diskussionen

Beteiligen Sie sich an Diskussionen in unserem GitHub-Repository. Wir freuen uns über Feedback und Vorschläge!

Öffnungszeiten

Als Open-Source-Projekt sind wir rund um die Uhr verfügbar. Antworten auf Anfragen können jedoch einige Zeit in Anspruch nehmen, da dies ein ehrenamtliches Projekt ist.
