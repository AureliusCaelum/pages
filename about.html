Über uns

Willkommen auf unserer "Über uns" Seite!

Unser Projekt

Diese Website wurde erstellt, um die Möglichkeiten von GitHub Pages zu demonstrieren. GitHub Pages ist ein kostenloser Service, der es ermöglicht, statische Websites direkt aus einem GitHub-Repository zu hosten.

Unsere Mission

Wir möchten zeigen, wie einfach es ist, eine professionell aussehende Website mit einfachen HTML- und CSS-Technologien zu erstellen. Diese Seite dient als Vorlage und Inspiration für andere Projekte.

Technologie

Diese Website nutzt:

  • HTML5 für die Struktur
  • CSS3 für das Design
  • GitHub Pages für das Hosting

Warum GitHub Pages?

GitHub Pages bietet mehrere Vorteile:

  • Kostenlos für öffentliche Repositories
  • Einfache Versionskontrolle durch Git
  • Schnelles und zuverlässiges Hosting
  • HTTPS-Unterstützung
  • Eigene Domain möglich
